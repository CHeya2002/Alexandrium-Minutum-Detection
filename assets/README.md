\# Project Assets



This directory contains selected visual materials from the project

\*\*"Classification of Alexandrium minutum Occurrences and Blooms in Maritime Context."\*\*



The assets are used primarily to illustrate the methodology and experimental

results presented in the main repository README.



\## Contents



This directory may include:



\- Project pipeline diagrams

\- Dataset sample images

\- Image annotation examples

\- Object detection examples

\- YOLOv8 prediction results

\- YOLO11 prediction results

\- RF-DETR prediction results

\- ResNet classification results

\- Training and validation curves

\- Model comparison plots

\- Evaluation metrics and confusion matrices



\## Purpose



The selected figures provide a concise visual overview of the project without

requiring readers to navigate through the complete academic report.



Selected assets may also be embedded directly in the main `README.md`.
